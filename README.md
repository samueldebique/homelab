# lab

Personal lab environment and security learning.
Runs on a Lenovo ThinkCentre M720q with Proxmox VE.

## Structure

| Folder | Description |
|--------|-------------|
| `homelab/` | Self-hosted services, Proxmox setup, and infrastructure guides |
| `thm/` | TryHackMe room notes and walkthroughs |
| `htb/` | Hack The Box box writeups |

## Homelab stack

Proxmox VE · Docker · Pi-hole · Vaultwarden · Nginx Proxy Manager · WireGuard · Home Assistant · AdGuard Home · Ollama

## Purpose

This repo documents my hands-on learning environment — both the infrastructure I've built and the security practice I do on top of it.
