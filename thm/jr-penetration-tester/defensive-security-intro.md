# Defensive Security Intro

## Summary
Overview of defensive security concepts. Simulated a Security Operations Center (SOC) analyst investigating alerts in a SIEM dashboard.

## Key concepts

- Defensive security = preventing and detecting intrusions
- Blue team handles defensive security, red team handles offensive
- SOC monitors networks and systems for malicious activity

**SOC areas of interest:**
- Vulnerabilities, policy violations, unauthorized activity, network intrusions

**Digital Forensics and Incident Response (DFIR) phases:**
- Preparation → Detection & Analysis → Containment, Eradication & Recovery → Post-Incident Activity

**Malware types:**
- Virus = spreads and corrupts files
- Trojan = disguised as legitimate software
- Ransomware = encrypts files, demands payment

## Notes
- Security Information and Event Management (SIEM) = aggregates security events from multiple sources into one dashboard
- Not all alerts are malicious — analyst judgment required
- Static malware analysis = inspect without running it
- Dynamic malware analysis = run in controlled environment and observe behaviour
